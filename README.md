
# Semantic HTML Page Layout Guide

A small learning project that shows how to structure a web page with semantic HTML5 tags.

![Semantic HTML Page Layout Guide](./Semantic%20HTML%20Page%20Layout%20Guide.png)

## What is Semantic HTML?

Semantic tags describe the **meaning** of content, not just how it looks. `<nav>` tells browsers, search engines and screen readers "these are navigation links". A plain `<div>` tells them nothing.

## Files

| File | Description |
|---|---|
| `semantic.html` | Example blog page built with semantic tags |
| `non-semantic.html` | The same page built only with `<div>`s, for comparison |
| `index.html` | Practice page: images, links and lists |
| `Semantic HTML Page Layout Guide.png` | Visual cheat sheet of the layout |

## Tags Covered

| Tag | Purpose |
|---|---|
| `<header>` | Introductory content for the page |
| `<nav>` | Navigation links |
| `<main>` | Main content of the page (one per page) |
| `<section>` | Groups related content by topic |
| `<article>` | Independent content, such as a blog post |
| `<figure>` / `<figcaption>` | A figure and its caption |
| `<aside>` | Related or supplementary content |
| `<details>` / `<summary>` | Expandable content |
| `<time>` | A date or time |
| `<address>` | Contact information |
| `<footer>` | Footer content for the page |
